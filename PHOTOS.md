# Фото и картинки: что куда класть

Все файлы кладём в **`public/assets/img/`** (видео — в `public/assets/video/`), в коде они
подключены как `assets/img/<имя файла>`. Ничего в коде править не нужно: пока файла нет — на его
месте зелёная плашка с подписью, как только файл появился — фото встаёт на место (обновите
страницу).

Правила для всех файлов: JPG, sRGB, имя строчными латинскими буквами (`nom-1.jpg`,
`gallery-07.jpg`), вес до ~300 КБ на кадр.

**Итого 13 фото** — все на месте: 3 в «О турнире», 2 в номинациях, 8 в галерее. Плюс 2 служебные
картинки и видео первого экрана. Портреты организаторов и логотипы партнёров понадобятся, когда
вернём эти блоки на страницу.

## Главный экран (hero) — ✅ готово

Видео в фоне, затемняется градиентом снизу, текст лежит слева-снизу. Кадр — бой двух бойцов,
зрители и фотограф на фоне; под затемнение подходит.

| Файл              | Статус  | Пропорции | Размер                            |
| ----------------- | ------- | --------- | --------------------------------- |
| `hero.mp4`        | ✅ есть | 16:9      | 1920×1080, 8 с, 25 fps, 2.9 МБ    |
| `hero-poster.jpg` | ✅ есть | 16:9      | 1920×1080, 151 КБ (кадр из видео) |

Что сделано с исходником: было 41 с / 20 МБ / со звуком. Взял фрагмент 16.5–24.5 с — ближний бой,
падение бойца; на телефоне узкий кадр обрезается по центру и бойцы остаются в кадре (широкие планы
арены в вертикаль не влезают). Убрал звук, сжал H.264 CRF 30, добавил `faststart`.
Исходник 41 с лежит в `source-media/hero-source.mp4` (папка в `.gitignore`, на сайт не попадает).

Если нужен другой фрагмент или длина — пересобрать одной командой:

```bash
ffmpeg -y -ss 16.5 -t 8 -i source-media/hero-source.mp4 -an \
  -vf "hqdn3d=2:1:3:3" -c:v libx264 -preset slow -crf 30 -pix_fmt yuv420p \
  -profile:v high -level 4.0 -movflags +faststart public/assets/video/hero.mp4
```

Постер — кадр из готового видео (1.5-я секунда):

```bash
ffmpeg -y -ss 1.5 -i public/assets/video/hero.mp4 -frames:v 1 -q:v 4 public/assets/img/hero-poster.jpg
```

Видео крутится в цикле, на паузу ставится, когда первый экран ушёл из вида, и не запускается у тех,
кто включил «уменьшить движение» в системе (останется постер).

## Как обрезались фото

Исходники — 8 кадров ~2500×1667 (3:2). Они лежат в `source-media/photos-raw/` (папка в `.gitignore`,
на сайт не попадает). Обрезка под слот — одной командой на файл:

```bash
# квадрат 1200×1200 из кадра 3:2
ffmpeg -y -i source.jpg -vf "scale=1200:1200:force_original_aspect_ratio=increase,crop=1200:1200" \
  -q:v 4 public/assets/img/gallery-02.jpg

# широкий 2:1
ffmpeg -y -i source.jpg -vf "scale=2000:1000:force_original_aspect_ratio=increase,crop=2000:1000" \
  -q:v 4 public/assets/img/gallery-01.jpg
```

Если кадр обрезался неудачно, поправьте точку кадрирования третьим параметром `crop`:
`crop=1200:1200:(iw-1200)/2:(ih-1200)*0.4` — 0 сверху, 1 снизу.
